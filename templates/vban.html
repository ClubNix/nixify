Stream VBAN

Cette page sert uniquement de pense-bete pour les membres qui souhaitent envoyer leur propre flux audio vers le mini PC du club.

Cible VBAN : {{ server_ip }}
Port UDP : 6980
  1. Ouvrez votre outil VBAN favori sur votre machine.
  2. Configurez un flux sortant vers l'adresse IP locale {{ server_ip }}.
  3. Utilisez le port 6980 pour envoyer le stream au mini PC relie a la chaine hi-fi du club.
  4. Choisissez un nom de stream explicite pour que l'equipe puisse l'identifier facilement.

Cette interface n'active pas elle-meme VBAN cote serveur : elle affiche seulement les informations de connexion pour les membres.
